# Yandex Discord Music Bot

Личный Discord-бот для воспроизведения треков из Яндекс Музыки на своем сервере.

## Что нужно

- Python 3.10+
- FFmpeg, доступный из терминала командой `ffmpeg`
- Discord bot token
- Токен Яндекс Музыки

## Установка

```powershell
cd C:\Users\Alexander\yandex-discord-music-bot
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -U pip
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
```

Скопируй `.env.example` в `.env` и заполни значения:

```powershell
Copy-Item .env.example .env
```

## Настройка Discord

В Discord Developer Portal:

1. Создай Application и Bot.
2. Включи `MESSAGE CONTENT INTENT`.
3. Пригласи бота на сервер с правами:
   - Connect
   - Speak
   - Send Messages
   - Read Message History
4. Для invite URL нужны scopes:
   - `bot`
   - `applications.commands`

Если при запуске появилась ошибка `PrivilegedIntentsRequired`, значит пункт `MESSAGE CONTENT INTENT` не включен или изменения не сохранены. Открой `Bot` -> `Privileged Gateway Intents`, включи `Message Content Intent`, нажми `Save Changes` и перезапусти бота.

## Получение токена Яндекс Музыки

```powershell
.\.venv\Scripts\python.exe get_yandex_token.py
```

Скрипт покажет ссылку и код. Открой ссылку, введи код, подтверди вход и скопируй строку `YANDEX_MUSIC_TOKEN=...` в `.env`.

## Запуск

```powershell
.\.venv\Scripts\python.exe bot.py
```

## Docker Compose

На сервере:

```bash
git clone https://github.com/tip141111-cyber/musicyandexbot.git
cd musicyandexbot
cp .env.example .env
```

Заполни `.env` реальными значениями:

```env
DISCORD_TOKEN=...
YANDEX_MUSIC_TOKEN=...
ALLOWED_USER_IDS=832292697322684417,708323370910875669,376344746303553536
OWNER_USER_IDS=832292697322684417
COMMAND_PREFIX=!
```

Запуск:

```bash
docker compose up -d --build
```

Проверка логов:

```bash
docker compose logs -f music-yandex-bot
```

Остановка:

```bash
docker compose down
```

Обновление после нового коммита:

```bash
git pull
docker compose up -d --build
```

## Команды

Основной способ управления - slash-команды. Они появляются во всплывающем меню Discord при наборе `/`.

- `/join` - подключить бота к твоему голосовому каналу
- `/play query` - найти и включить трек
- `/search_track query` - показать 10 найденных треков
- `/search_artist query` - показать 10 найденных исполнителей
- `/select number` - включить трек из последнего поиска или добавить до 20 треков выбранного исполнителя
- `/pause` - пауза
- `/resume` - продолжить
- `/skip` - пропустить текущий трек
- `/stop` - очистить очередь и остановить
- `/leave` - отключить бота
- `/queue` - показать очередь
- `/queue_play number` - включить трек из очереди по номеру
- `/now` - что сейчас играет
- `/commands` - показать команды

После первого запуска или изменения команд Discord может показывать slash-команды не сразу, иногда нужно подождать несколько минут.

Старые `!`-команды оставлены как запасной вариант:

- `!join` / `!зайди` / `!подключись` - подключить бота к твоему голосовому каналу
- `!play запрос` / `!играть запрос` / `!включи запрос` - найти и добавить трек в очередь
- `!search запрос` / `!поиск запрос` / `!поиск_трек запрос` / `!трек запрос` - показать 10 найденных треков
- `!artist запрос` / `!исполнитель запрос` / `!поиск_исполнитель запрос` - показать 10 найденных исполнителей
- `1`, `2`, `3` ... `10` - включить трек или добавить треки выбранного исполнителя
- `!select номер` / `!выбрать номер` / `!номер номер` - включить трек или добавить треки выбранного исполнителя
- `!pause` / `!пауза` / `!паузы` - пауза
- `!resume` / `!продолжить` / `!дальше` - продолжить
- `!skip` / `!скип` / `!пропусти` - пропустить текущий трек
- `!stop` / `!стоп` / `!останови` - очистить очередь и остановить
- `!leave` / `!выйди` / `!отключись` - отключить бота
- `!queue` / `!очередь` - показать очередь
- `!queue_play номер` / `!играть_из_очереди номер` - включить трек из очереди по номеру
- `!np` / `!сейчас` / `!играет` - что сейчас играет
- `!help` / `!помощь` / `!команды` - показать команды
- `!` - показать подсказку с командами

После запуска трека бот показывает кнопки управления: `Пауза`, `Играть`, `Следующая`, `Стоп`. Это замена горячим клавишам внутри Discord: настоящие клавиатурные хоткеи для бота Discord не поддерживает.

## Приватный доступ

Чтобы ботом могли управлять только выбранные пользователи, укажи их Discord ID в `.env`:

```env
ALLOWED_USER_IDS=123456789012345678,987654321098765432
```

Обычные пользователи могут искать музыку, запускать треки, ставить паузу, переключать, выбирать очередь, останавливать воспроизведение и отключать бота.

Владельцы указываются отдельно:

```env
OWNER_USER_IDS=123456789012345678
```

Владельцы указаны отдельно на будущее, если потом захочешь добавить команды только для себя.

Если хочешь дать доступ роли, укажи ID роли:

```env
ALLOWED_ROLE_IDS=123456789012345678
```

После изменения `.env` перезапусти бота.

## Важное

Это личный проект под твой аккаунт и твой сервер. Не публикуй токены, не выкладывай `.env` в GitHub и не используй бота для публичной раздачи музыки.
